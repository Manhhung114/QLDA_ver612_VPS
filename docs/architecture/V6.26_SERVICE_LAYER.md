# V6.26 — Service Layer

## Mục tiêu

V6.26 đặt một lớp ứng dụng ổn định giữa Streamlit/systemd worker và domain
BOQ, IPC, VO, Tiến độ, Files, Jobs. Mục tiêu là ngừng để adapter giao diện gọi
thẳng persistence hoặc file versioned, đồng thời chuẩn bị đúng boundary để
V6.27 FastAPI tái sử dụng nghiệp vụ mà không sao chép logic.

## Luồng production

```text
Streamlit / systemd worker / V6.27 FastAPI
                 |
                 v
          qlda.services.*
                 |
                 v
         qlda.modules.<domain>
                 |
                 v
       persistence / infrastructure
                 |
                 v
 PostgreSQL + local VPS file storage
```

Worker systemd hiện chạy `python -m qlda.modules.excel.worker`. Từ V6.26 worker
này gọi `ExcelImportService`, `FileService` và `JobService`; nó không còn import
trực tiếp các file `*_v624.py` hoặc `local_vps_backend_v622.py`.

## Services

- `BOQService`: parse, batch persistence, snapshot workbook và kết quả xác minh.
- `IPCService`: parse một Claim/IPC, revision và batch persistence.
- `VOService`: parse VO, revision, batch persistence và kết quả xác minh.
- `ScheduleService`: parse Excel tiến độ, tính status-date và batch persistence.
- `ExcelImportService`: dispatch `BOQ`, `IPC`, `VO`, `SCHEDULE_EXCEL`,
  `WORKBOOK_SCAN`.
- `FileService`: boundary cho local file path, metadata, upload ticket, list và
  trash file.
- `JobService`: boundary cho queue, claim, progress, cancel, retry, heartbeat.

## Compatibility

V6.26 không đổi schema PostgreSQL, parser nghiệp vụ, công thức, revision,
rollback hay quy tắc xác minh số dòng của V6.24. Các implementation cũ vẫn nằm
sau facade `qlda.modules.*`/`qlda.shared.legacy` trong giai đoạn strangler.

Monkey patch PostgreSQL còn cần cho `CloudDatabase` legacy nhưng đã được gom
vào duy nhất `qlda.infrastructure.database.make_database()`. Domain service và
worker không tự cài adapter nữa.

## Quy tắc từ V6.26

1. Code mới không được import trực tiếp file versioned `*_v622.py`/`*_v624.py`
   từ presentation hoặc worker.
2. UI/API phải gọi `qlda.services.*` cho use case mới.
3. Service không import Streamlit.
4. Transaction và xác minh PostgreSQL vẫn thuộc persistence/domain hiện hữu.
5. V6.27 chỉ thêm HTTP adapter trên các service này, không viết lại nghiệp vụ.
