# V7.5 – Native Import Engines & Compatibility Retirement

V7.5 moves the BOQ, IPC, VO and Schedule background import engines into the
`src/qlda/import_engines` package and removes the V6.25/V6.26 service/module
facades from the production worker path.

## Runtime path

`qlda.modules.excel.worker -> application ExcelImportUseCases -> NativeExcelImportAdapter -> qlda.import_engines.*`

`NativeExcelImportAdapter` no longer imports `qlda.runtime`, `qlda.services`,
`qlda.modules.*` business facades or `qlda.shared.legacy`.

## Data invariants retained

- BOQ: expected/scanned/prepared/written/failed row verification and full
  transaction rollback on gaps/cancellation.
- IPC: independent claim identity, SHA/batch idempotency, revision history,
  approved/disbursed/payment-status preservation and rollback.
- VO: independent revision history plus approved amount, funding source and
  status preservation.
- Schedule: only rows created by the background Excel pipeline
  (`source_type = schedule_excel:*`) are replaced; manual/MPP tasks are kept.

## Retirement

V7.5 removes:

- `src/qlda/services/`
- `src/qlda/modules/boq/`
- `src/qlda/modules/ipc/`
- `src/qlda/modules/vo/`
- `src/qlda/modules/schedule/`
- `src/qlda/modules/excel/jobs.py`
- `src/qlda/shared/legacy.py`

The root V6.22 semantic helpers and root V6.24 engine files remain temporarily
for the Streamlit/AI compatibility runtime and historical regression tests. The
worker no longer loads root V6.24 engine files. Database/AI compatibility still
uses the centralized `qlda.runtime.legacy_import`; removing that final semantic
runtime is intentionally outside V7.5.

## CI gate

`v750-native-import-engines-check.yml` verifies engine packaging, service/facade
retirement, unchanged FastAPI contracts, worker entrypoint, and the BOQ/IPC/VO/
Schedule persistence invariants above.
