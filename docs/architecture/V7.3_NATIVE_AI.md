# V7.3 — Native AI

## Mục tiêu

V7.3 loại bỏ tầng `LegacyAIAdapter` và hai façade V6.26 `qlda.services.ai` / `qlda.services.access` khỏi runtime Clean Architecture. FastAPI và application use cases tiếp tục dùng `AIPort`, nhưng composition root giờ nối trực tiếp sang `NativeAIAdapter`.

## Luồng phụ thuộc

```text
FastAPI / Presentation
        |
        v
Application AIUseCases
        |
        v
Domain AIPort
        ^
        |
NativeAIAdapter
        |
        +-- OpenAIProjectAssistant
        +-- GeminiProjectAssistant
        +-- AI context installers
        +-- contractor workspace ContextVar guard
```

`NativeAIAdapter` không import `qlda.services` và không import `qlda.shared.legacy`. Các engine AI/context root-level đã được kiểm chứng vẫn được load lazy qua `qlda.runtime.legacy_import`; đây là engine compatibility nội bộ, không còn là application/service-layer adapter.

## Invariants giữ nguyên

- Giữ nguyên các endpoint `/api/v1/ai/ask`, `/schedule-risk`, `/report`, `/legal`, `/test`.
- Giữ nguyên lựa chọn provider OpenAI/Gemini và biến môi trường hiện hữu.
- Giữ nguyên `workspace_scope` dùng `ContextVar` để contractor không nhìn dữ liệu workspace khác.
- Giữ nguyên chuẩn lỗi `AIApplicationError` ở domain, gồm `code`, `retryable`, `action`.
- Không thay DB schema, không thay BOQ/IPC/VO/Schedule/Excel transaction.
- AI engine chỉ bootstrap ở request AI đầu tiên; `get_application()` không mở DB hoặc gọi provider.
