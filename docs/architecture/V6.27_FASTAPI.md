# QLDA V6.27 — FastAPI for Jobs / Files / AI / Search

## Mục tiêu

V6.27 thêm một HTTP adapter chính thức nhưng **không tách microservice** và không sao chép
nghiệp vụ. Kiến trúc vẫn là Modular Monolith:

`Nginx -> qlda.presentation.api -> qlda.services -> qlda.modules/infrastructure -> compatibility`

FastAPI chỉ chịu trách nhiệm HTTP, validation, auth dependency và response. Parser Excel,
transaction, revision, rollback, PostgreSQL row verification và các luật nghiệp vụ vẫn nằm
sau Service Layer V6.26.

## API surface

- `GET /api/health`
- `/api/v1/jobs`: liệt kê, đọc, enqueue và hủy background Excel job.
- `/api/v1/files`: metadata, file list/count, upload ticket, download và trash.
- `/api/v1/ai`: hỏi dự án, rủi ro tiến độ, draft report, legal QA và Admin test.
- `POST /api/v1/search`: tìm kiếm read-only theo project/workspace trên các bảng nghiệp vụ.
- OpenAPI: `/api/docs`, `/api/redoc`, `/api/openapi.json`.

## Authentication và authorization

API **không tạo tài khoản/token riêng**. Header `Authorization: Bearer <session-token>` dùng
chính session QLDA hiện hữu trong PostgreSQL.

`ProjectAccessService` áp dụng lại contractor access + default-workspace Admin-only:

- Admin có thể dùng master/default workspace và AI toàn dự án.
- Người dùng không phải Admin chỉ truy cập workspace nhà thầu được phép.
- AI của non-Admin được pin bằng ContextVar vào đúng workspace.
- API file/job cũng kiểm tra project scope trước khi trả hoặc thay đổi dữ liệu.

## AI

`AIService` bootstrap cùng stack production: runtime settings, Gemini resilience, PostgreSQL
live context, Claim/VO context, BOQ full-scan, material/labor recovery và contractor context.
Do đó FastAPI và Streamlit dùng cùng nguồn dữ liệu/logic AI, không tạo snapshot song song.

## Deploy

- `qlda-api.service`: Uvicorn `127.0.0.1:8001`, một worker để giữ compatibility patch state
  nhất quán.
- Nginx proxy `/api/` vào `8001`.
- `vps/reconcile_api_v627.sh` chỉ chèn location `/api/` nếu thiếu, giữ nguyên cấu hình HTTPS
  do Certbot quản lý.
- FastAPI/uvicorn được cài từ `requirements.txt`.
- API health phải trả HTTP 200 trước khi reconcile hoàn tất.

## Invariants

V6.27 không thay đổi:

- schema nghiệp vụ PostgreSQL hiện hữu;
- parser/công thức BOQ, IPC/Claim, VO, Schedule;
- workflow phê duyệt và quyền hiện hữu;
- file gốc trên SSD;
- idempotency/revision;
- transaction/rollback;
- xác minh số dòng PostgreSQL của background import.

V7 có thể di chuyển implementation legacy dần dần, nhưng client HTTP V6.27 chỉ phụ thuộc
Service Layer ổn định.
