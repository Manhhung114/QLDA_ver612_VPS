# QLDA V7.2 — Native Project Access

## Mục tiêu

V7.2 loại `LegacyProjectAccessAdapter` khỏi composition root và chuyển kiểm soát
quyền dự án/workspace sang adapter PostgreSQL native. API contract, bảng dữ liệu
và cách phân quyền nhà thầu được giữ tương thích với các phiên bản trước.

## Luồng mới

```text
FastAPI / Worker / Presentation
            |
     Application Use Cases
            |
        ProjectAccessPort
            |
 NativeProjectAccessAdapter
            |
       PostgreSQL
  projects
  project_contractors
  project_user_contractor_access
```

`NativeProjectAccessAdapter` không import `qlda.services`, `qlda.shared.legacy`,
`contractor_workspace_v622` hay `contractor_access_control_v622`.

## Tương thích được giữ

- Admin được phép làm việc ở master project và các workspace đang hoạt động.
- Tài khoản không phải nhà thầu chỉ thấy các workspace nhà thầu đang hoạt động.
- Tài khoản `CONTRACTOR` chỉ được vào workspace đã gán.
- Nếu dự án chỉ có đúng một nhà thầu hoạt động, tài khoản contractor cũ chưa có
  binding được tự gán an toàn như cơ chế V6.22.
- Dự án chưa từng có contractor row được tạo default contractor cho master
  workspace; contractor đã ngưng hoạt động không bị tự kích hoạt lại.
- Không đổi endpoint FastAPI, schema nghiệp vụ BOQ/IPC/VO/Schedule hoặc queue V6.24.
