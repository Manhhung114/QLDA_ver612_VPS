# V7.6.1 Color Theme

The packaged Streamlit runtime keeps the V7 compact layout and uses a brighter production-safe base palette.

- Primary action color: blue `#1D4ED8`
- App background: very light blue `#F7FAFF`
- Secondary surfaces / widget backgrounds: `#EAF2FF`
- Main text: navy `#172033`
- The existing V7 compact CSS continues to provide navy headers, colored status chips, white cards and warning/success accents.
- Business logic, persistence, permissions and workflow state are unchanged.

The production theme is defined in `.streamlit/config.toml`; the compact visual layer remains in `src/qlda/runtime_core/ui_v7_compact.py`.
