# V7.6.1 Color Theme

The packaged Streamlit runtime keeps the V7 compact layout and adds a richer presentation-only palette.

- Primary: blue `#2563eb`
- Accent: cyan `#0891b2`
- Secondary accent: purple `#7c3aed`
- Sidebar: light blue gradient for readability
- Active tabs, primary actions, metrics, forms and data grids receive consistent visual emphasis
- Business logic, persistence, permissions and workflow state are unchanged

Regression gate: `.github/workflows/v761-color-theme-check.yml`.
