# V7.6 Color Theme

The production Streamlit runtime now uses one synchronized visual system across the whole QLDA app. The theme is presentation-only; business logic, persistence, permissions and workflow state are unchanged.

## Core palette

- Primary action blue: `#1D4ED8`
- Deep navy / branded headers: `#0F2747`
- Accent cyan: `#0EA5E9`
- App background: `#F4F7FC`
- Secondary/widget background: `#EAF2FF`
- Main text: `#14213D`
- Muted text: `#64748B`
- Success: `#15803D`
- Warning: `#B45309`
- Error: `#B91C1C`

## Synchronized components

The global V7 visual layer applies the same palette and interaction language to:

- project header / contractor workspace banner;
- sidebar and main page background;
- all tab groups and active-tab states;
- primary and secondary buttons;
- metrics, cards, forms and expanders;
- text inputs, text areas, select boxes and multiselect tags;
- file upload areas;
- dataframes and data editors;
- progress bars, alerts, status blocks and section headings;
- desktop and mobile layouts.

Primary actions use a blue gradient, secondary actions remain white with blue hover states, and warning/success surfaces retain semantic orange/green accents. The project header uses a navy-to-blue gradient for stronger visual identity while maintaining high text contrast.

The base Streamlit palette is defined in `.streamlit/config.toml`; the complete synchronized visual layer is defined in `src/qlda/runtime_core/ui_v7_compact.py` and is installed globally by the production Streamlit entrypoint.
